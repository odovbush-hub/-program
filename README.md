# EduSpace 🎓

**Інтерактивна платформа тестування та навчання для закладу освіти.**
Кросплатформений вебзастосунок (PWA): встановлюється на комп'ютер і смартфон, працює без інтернету.

Тема практики: *«Створення інтерактивного навчального тренажера чи платформи тестування для закладу освіти»*.

---

## Як запустити у VS Code

1. Розпакуйте архів і відкрийте папку `eduspace` у VS Code (**File → Open Folder**).
2. Встановіть розширення **Live Server** (автор Ritwick Dey). VS Code сам запропонує його, бо воно вказане в рекомендаціях проєкту.
3. Відкрийте `index.html`, натисніть правою кнопкою → **Open with Live Server** (або кнопку **Go Live** унизу праворуч).
4. Застосунок відкриється в браузері за адресою `http://127.0.0.1:5500`.

> Можна відкрити `index.html` і подвійним кліком: усе працюватиме, окрім встановлення та офлайн-режиму (для них потрібен сервер).

## Як встановити як застосунок

- **На комп'ютері (Chrome / Edge):** у шапці з'явиться кнопка **«Встановити»** (або іконка ⊕ в адресному рядку). Після встановлення EduSpace відкривається в окремому вікні з власною іконкою.
- **На телефоні:** телефону потрібна адреса з `https://`. Найпростіше безкоштовно розмістити проєкт:
  - **Netlify Drop:** зайдіть на app.netlify.com/drop і перетягніть туди папку `eduspace`, і ви одразу отримаєте посилання;
  - або **GitHub Pages:** завантажте проєкт у репозиторій → Settings → Pages.

  Відкрийте посилання на телефоні → меню браузера → **«Додати на головний екран» / «Встановити застосунок»**.

## Можливості

| Функція | Опис |
|---|---|
| **Реєстрація та вхід** | Обов'язкова реєстрація з вибором ролі (студент / викладач), логін і пароль (зберігається хеш SHA-256 із сіллю) |
| **Ролі** | Студент: курси, тести, прогрес, сертифікати. Викладач: курси, конструктор тестів, журнал результатів |
| **Каталог курсів** | 12 курсів у 6 категоріях: Інформатика та IT, Математика, Історія України, Українська мова та література, Англійська мова, Природничі науки. Фільтр за категорією та пошук |
| **Журнал викладача** | Результати студентів, фільтр за групою та курсом, рейтинг студентів, експорт у Excel (CSV) |
| **Режим «Тренування»** | Миттєва перевірка, підсвічування правильної відповіді, блок «Чому так?» |
| **Режим «Іспит»** | Таймер 3 хв, підказки вимкнено, результат лише в кінці, автозавершення по часу |
| **Контроль чесності** | Фіксація виходів зі сторінки під час іспиту (перемикання вкладки чи програми) |
| **Перемішування** | Порядок питань і варіантів змінюється при кожній спробі |
| **Гейміфікація** | Шкала прогресу, лічильник серії 🔥 Streak, бали (+10, бонус +5 за серію від 3) |
| **Досягнення** | 9 бейджів: «Перший крок», «У вогні», «Відмінник», «Швидкий розум», «Чесна гра» та інші |
| **Результати** | Кільцева діаграма, статистика, розбір помилок з поясненнями |
| **Робота над помилками** | Повторне проходження лише тих питань, де була помилка |
| **Сертифікат** | При результаті від 70%: ПІБ, група, дата, номер, QR-код з даними, друк / збереження в PDF |
| **Мій прогрес** | Графік останніх спроб, статистика за модулями, «слабкий» модуль, історія, сертифікати |
| **Конструктор тестів** | Режим викладача: створення тестів, збереження в `localStorage`, кнопка «Заповнити прикладом» |
| **Експорт / імпорт** | Викладач завантажує тест у файл `.json` і надсилає групі, студенти імпортують його одним кліком |
| **Дизайн** | Темна палітра: чорний фон `#000000`, неоновий акцент `#e4ff3c`, помилки `#ff3366` |
| **Клавіатура** | `1`–`4`: вибір відповіді, `Enter`: далі, `Esc`: закрити вікно |
| **PWA / офлайн** | Встановлення на ПК і телефон, робота без інтернету (Service Worker) |

## Технології

- **HTML5, CSS3, JavaScript (ES2020)**: без фреймворків, логіка на «чистому» JS
- **Tailwind CSS 3**: утилітарні стилі, кольори через CSS-змінні
- **Lucide**: набір іконок
- **qrcode-generator**: QR-код на сертифікаті
- **canvas-confetti**: анімація конфеті
- **Web Storage API (`localStorage`)**: збереження тестів, історії, досягнень
- **PWA**: Web App Manifest + Service Worker (стратегія «спочатку мережа»)
- **Шрифт Manrope**: з підтримкою кирилиці

Усі бібліотеки та шрифти лежать у проєкті локально, тому застосунок не залежить від інтернету.

## Структура проєкту

```
eduspace/
├── index.html              # головна сторінка, шапка, підключення скриптів
├── manifest.webmanifest    # опис PWA: назва, іконки, кольори
├── sw.js                   # Service Worker: кешування для офлайн-роботи
├── css/styles.css          # зібрані стилі (результат Tailwind)
├── src/input.css           # вихідні стилі: палітра, компоненти, анімації, друк
├── tailwind.config.js      # налаштування Tailwind (кольори, шрифт)
├── js/
│   ├── data.js             # категорії, курси та питання
│   ├── storage.js          # робота з localStorage
│   ├── auth.js             # реєстрація, вхід, хешування паролів
│   ├── utils.js            # допоміжні функції (дати, сповіщення, конфеті…)
│   ├── badges.js           # досягнення та їх перевірка
│   ├── app.js              # основна логіка: екрани, тестування, конструктор, журнал
│   ├── pwa.js              # реєстрація Service Worker, кнопка «Встановити»
│   └── vendor/             # бібліотеки (Lucide, QR, конфеті)
├── fonts/                  # шрифт Manrope
└── icons/                  # іконки застосунку
```

## Зберігання даних

Усі дані зберігаються в браузері (`localStorage`) і нікуди не надсилаються:

| Ключ | Що зберігається |
|---|---|
| `eduspace_users` | користувачі: ПІБ, логін, роль, група, хеш пароля |
| `eduspace_session` | хто зараз увійшов |
| `eduspace_custom_tests` | тести викладачів (з категорією та автором) |
| `eduspace_attempts` | усі спроби (користувач, курс, режим, %, час, серія, виходи) |
| `eduspace_user_badges` | досягнення кожного користувача |
| `eduspace_certs` | видані сертифікати |

> Реєстрація працює в межах браузера одного пристрою (наприклад, комп'ютерного класу). Наступний крок розвитку — серверна частина та база даних, щоб акаунти й журнал були доступні з будь-якого пристрою.

Оскільки `localStorage` прив'язаний до браузера, для передачі тестів між пристроями є **експорт/імпорт у файл JSON**.

## Як додати або змінити питання

Відкрийте `js/data.js`. Кожне питання має такий вигляд:

```js
// кожен курс має поле category: 'it' | 'math' | 'history' | 'ukrainian' | 'english' | 'science'
{
  text: 'Текст питання',
  options: ['Варіант A', 'Варіант B', 'Варіант C', 'Варіант D'],
  correct: 1,               // номер правильного варіанта, рахуючи з 0 (тут — B)
  explanation: 'Пояснення «Чому так?»',
}
```

## Якщо змінюєте стилі

Файл `css/styles.css` збирається з `src/input.css` за допомогою Tailwind. Якщо додаєте нові класи Tailwind у HTML/JS або змінюєте `src/input.css`, перезберіть стилі (потрібен [Node.js](https://nodejs.org)):

```bash
npm install          # один раз
npm run build:css    # зібрати стилі
npm run watch:css    # або: автоматично перезбирати під час роботи
```

## Налаштування

Основні параметри на початку `js/app.js`:

```js
const EXAM_SECONDS = 180;   // час іспиту (с)
const PASS_PERCENT = 70;    // поріг для сертифіката (%)
const POINTS_CORRECT = 10;  // бали за правильну відповідь
const STREAK_BONUS = 5;     // бонус за серію
```
